\# 💳 Credit Card Fraud Detection \& Analytics



\## 📌 Project Overview



This project detects fraudulent credit card transactions using Machine Learning and presents business insights through analytics and visualization.



The project combines Python, SQL, Power BI and a REST API to demonstrate an end-to-end data analytics workflow.



\---



\## 🎯 Objectives



\- Detect fraudulent credit card transactions.

\- Handle highly imbalanced data.

\- Build a machine learning prediction model.

\- Analyse transaction patterns.

\- Visualize insights using Power BI.

\- Provide fraud prediction through a REST API.



\---
